iTowns is an open-source JavaScript framework built on [Three.js](https://threejs.org/) for visualizing geospatial data in 2D and 3D on the web. It supports a wide range of geospatial formats and services, including WMS, WMTS, vector tiles, GeoJSON, GPX, and 3D Tiles, which can be displayed as maps, terrain, vector features, and 3D models.

> If you are looking for an interactive tutorial, please look at the [Getting started page](tutorials/Fundamentals.md) instead.
